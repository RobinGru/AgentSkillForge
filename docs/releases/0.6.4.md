# AgentSkillForge 0.6.4

## English

### Changed

- Expanded `product-interface-engineering` routing guidance with common UI/UX and
  frontend requests, interaction states, accessibility, and responsive/mobile
  behavior.
- Added concise German and English interface-routing evals for modals,
  navigation, supplied designs, focus behavior, and error recovery.
- Runtime eval reports now distinguish response-contract results from routing
  assessment; routing is `not_available` unless a client supplies reliable
  selected-skill metadata.

### Fixed

- Removed the conflicting positive token-only interface eval. Isolated visual
  token and spacing changes remain outside the skill's activation boundary.

## Deutsch

### Geändert

- Die Routing-Hinweise für `product-interface-engineering` decken nun typische
  UI/UX- und Frontend-Anfragen, Interaktionszustände, Accessibility sowie
  responsives und mobiles Verhalten ab.
- Ergänzt wurden kurze deutsche und englische Interface-Routing-Evals für
  Modals, Navigation, vorgegebene Designs, Fokusverhalten und Fehlerbehebung.
- Runtime-Eval-Reports trennen nun Antwortvertrag und Routing-Bewertung;
  Routing bleibt `not_available`, bis ein Client belastbare
  Skill-Auswahlmetadaten liefert.

### Behoben

- Der widersprüchliche positive Eval für reine Token-Änderungen wurde entfernt.
  Isolierte visuelle Token- und Spacing-Änderungen bleiben außerhalb der
  Aktivierungsgrenze des Skills.
