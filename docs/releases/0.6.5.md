# AgentSkillForge 0.6.5

## English

### Changed

- Reorganized the source catalog into `core`, `planning`, `quality`, and
  `specialized` domains. Installation remains flat: each installed top-level
  directory is one complete skill.
- Added `repository-onboarding` and `repository-knowledge-curation` for
  evidence-based project orientation and durable repository knowledge.
- Added `feature-delivery` for sequential execution of tracked feature tasks,
  and documented the associated canonical feature artifacts.
- Added a portable flat ZIP bundle builder and an all-in-one `AGENTS.md`
  template for projects that prefer one compact guidance file.
- Condensed skill contracts, moved detailed material into on-demand references,
  and expanded German and English routing and runtime-eval coverage.
- Validation workflows now run on pull requests and can be started manually.

### Fixed

- Release-version validation now checks skill metadata in the categorized source
  layout.
- Local link validation excludes generated and virtual-environment directories.

## Deutsch

### Geändert

- Der Quellkatalog ist jetzt in die Bereiche `core`, `planning`, `quality` und
  `specialized` gegliedert. Die Installation bleibt flach: Jedes oberste
  installierte Verzeichnis ist ein vollständiger Skill.
- `repository-onboarding` und `repository-knowledge-curation` ergänzen
  evidenzbasierte Projektorientierung und dauerhaftes Repository-Wissen.
- `feature-delivery` führt getrackte Feature-Aufgaben strikt sequenziell aus;
  die zugehörigen kanonischen Feature-Artefakte sind dokumentiert.
- Ein portabler Builder für flache ZIP-Bundles sowie eine All-in-one-Vorlage
  `AGENTS.md` unterstützen Projekte, die eine kompakte Anweisungsdatei
  bevorzugen.
- Skill-Verträge wurden verdichtet, Details in bedarfsgesteuerte Referenzen
  verschoben sowie deutsche und englische Routing- und Runtime-Evals erweitert.
- Validierungsworkflows laufen jetzt bei Pull Requests und können manuell
  gestartet werden.

### Behoben

- Die Release-Versionsprüfung prüft Skill-Metadaten jetzt auch im kategorisierten
  Quelllayout.
- Die lokale Link-Prüfung schließt generierte Verzeichnisse und virtuelle
  Umgebungen aus.
