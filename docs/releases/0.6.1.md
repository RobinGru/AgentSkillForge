# AgentSkillForge 0.6.1

## English

### Added

- Added the `feature-lifecycle` skill for durable, revision-bound coordination of
  one substantial feature across sessions, agents, and independent work units.
- Added a compact lifecycle model with readiness fields, evidence requirements,
  explicit state guards, acceptance-proof mapping, parallel-work boundaries, and
  one safe next action.
- Added portable artifact templates for a feature index, canonical implementation
  record, parallel work units, and handoff boundaries.

### Changed

- Connected `feature-specification`, `project-discovery`, `solution-framing`,
  `safe-code-change`, `compatibility-migration`, and `session-handoff` to the
  lifecycle boundary without transferring their ownership responsibilities.
- Updated the optional `AGENTS.md` template, skill catalog, package distribution,
  static eval manifest, runtime contract fixture, and installer coverage.

### Verification

- Added lifecycle-specific static and runtime contract coverage.
- The release version is `0.6.1` for the package and every distributed skill.

## Deutsch

### Hinzugefügt

- Der neue Skill `feature-lifecycle` koordiniert ein größeres Feature dauerhaft
  und revisionsgebunden über Sitzungen, Agenten und unabhängige Arbeitseinheiten.
- Das kompakte Lifecycle-Modell enthält Readiness-Felder, Evidenzanforderungen,
  explizite Zustands-Gates, Akzeptanznachweise, Grenzen für parallele Arbeit und
  genau eine sichere nächste Aktion.
- Portable Vorlagen für Feature-Index, kanonischen Implementierungsdatensatz,
  parallele Arbeitseinheiten und Handoff-Grenzen wurden ergänzt.

### Geändert

- `feature-specification`, `project-discovery`, `solution-framing`,
  `safe-code-change`, `compatibility-migration` und `session-handoff` sind an
  die Lifecycle-Grenze angebunden, behalten aber ihre jeweiligen Zuständigkeiten.
- Die optionale `AGENTS.md`-Vorlage, der Skill-Katalog, die Paketdistribution,
  das statische Eval-Manifest, die Runtime-Fixture und die Installer-Abdeckung
  wurden aktualisiert.

### Verifikation

- Lifecycle-spezifische statische und Runtime-Contract-Evals wurden ergänzt.
- Die Release-Version `0.6.1` gilt für das Paket und alle verteilten Skills.
